=========================================================
   NOTE TECHNIQUE
=========================================================

Attributs UNIVERSELS (partagés entre plusieurs catégories) :
  → Couleur, Marque

Attributs SPÉCIFIQUES à une catégorie :
  → Volume (ml)        : Parfums uniquement
  → Pointure           : Chaussures uniquement
  → Stockage / RAM     : Téléphones & Ordinateurs
  → Connectivité       : Ordinateurs & Bracelets connectés
  → Tour de poignet    : Bracelets connectés uniquement

Conseil : dans votre base de données, définir les attributs
universels une seule fois et les réutiliser via des relations,
pour éviter la duplication et faciliter les filtres de recherche.
