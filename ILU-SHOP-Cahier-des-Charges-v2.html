Vision

Vision &
Positionnement

Ce que ILU SHOP est, ce qu'il représente et pour qui il est conçu.

Concept Fondateur

ILU SHOP — "I Love You Shop"

ILU SHOP est une plateforme e-commerce premium positionnée sur deux univers complémentaires : la Mode (vêtements, chaussures, vestes, accessoires) et le High-tech (téléphones, ordinateurs, tablettes). Le nom ILU — "I Love You" — exprime une relation émotionnelle forte avec les produits et la clientèle. Ce n'est pas un simple shop, c'est une expérience de découverte et de style.

Cible & Positionnement

ILU SHOP s'adresse en priorité à une clientèle Mode & Lifestyle connectée, sensible à l'esthétique, qui attend d'une plateforme e-commerce qu'elle lui parle visuellement. La plateforme est conçue pour le marché congolais et international — d'où le système bi-devise USD/CDF.

👗

Mode — Cœur de l'offre

Une catégorie Mode unifiée (vêtements, chaussures, vestes, accessoires) sans distinction homme/femme/enfant dans la navigation principale. Les filtres permettent l'affinement.

📱

High-Tech — Offre complémentaire

Téléphones, ordinateurs, tablettes. Renforce le positionnement lifestyle et tech de la plateforme.

⭐

Section "À la une"

Sélection éditoriale manuelle. Produits mis en avant avec photos découpées (sans fond) pour un effet d'incrustation premium, carousel hero en page d'accueil.

Politique Images — Sans Fond Obligatoire

Instruction Obligatoire pour les Administrateurs

📸 Règle d'or : toute image produit doit être sans fond

Pour garantir l'effet d'incrustation premium qui caractérise ILU SHOP — notamment sur la section "À la une" et le hero — chaque image produit uploadée doit être sur fond transparent (fichier PNG avec canal alpha) ou sur fond blanc pur (#FFFFFF) pour traitement automatique. Cette règle est non négociable pour les produits mis en avant. Le système IA prend le relais si l'admin uploade une image avec fond.

Deux voies pour obtenir des images sans fond

Voie A — Recommandée : l'admin fournit directement l'image découpée

  • Format attendu : PNG avec transparence (canal alpha)
  • Résolution minimale : 1000×1000 px
  • Fond blanc pur (#FFFFFF) accepté si PNG impossible — le système IA découpera automatiquement
  • Un guide visuel est affiché dans le tableau de bord admin pour illustrer le bon format
  • Les images mal formatées déclenchent un avertissement (pas un blocage) avec proposition de traitement IA

Voie B — Pipeline IA automatique (fallback)

Système Bi-Devise
USD / CDF

Dollar Américain comme monnaie principale, Franc Congolais comme monnaie secondaire affichée.

Principe Directeur

Dollar ($) en référence, Franc Congolais (FC) en équivalent

Tous les prix sont saisis et stockés en Dollars Américains (USD). Le Franc Congolais (CDF) est affiché en équivalent calculé dynamiquement selon un taux de change configurable par l'administrateur. Le client voit les deux montants en permanence — le dollar en grand, le franc congolais en dessous ou à côté, en style secondaire.

Les prix sont toujours saisis et stockés en USD dans la base de données. L'équivalent en Franc Congolais est calculé dynamiquement via le taux de change et n'est jamais enregistré. Cela évite toute désynchronisation en cas de changement de taux.

Sélecteur de Devise (Frontend)

  • Un sélecteur USD / CDF dans la navbar permet au client de passer l'affichage en priorité CDF
  • En mode CDF : le franc congolais s'affiche en grand, le dollar en petit à côté
  • Préférence sauvegardée en cookie (visiteurs) et en profil (clients connectés)
  • Valeur par défaut : USD

Commandes NOUVEAU

Chat Commande
& Livraison

Un système de messagerie intégré remplace le tunnel de paiement classique — paiement convenu entre client et admin, options de livraison flexibles.

Pourquoi ce système

L'humain au cœur de la transaction

En l'absence de passerelle de paiement intégrée (Stripe, etc.), ILU SHOP adopte une approche conversationnelle : quand un client souhaite commander, un chat s'ouvre directement avec l'équipe ILU SHOP. Le paiement (Mobile Money, virement, cash) et la logistique (livraison à domicile ou retrait en boutique) sont convenus en temps réel. C'est plus humain, plus flexible, et parfaitement adapté au marché local.

Parcours Client — Déclenchement du Chat

  1. Le client consulte un ou plusieurs produits, les ajoute à son panier
  2. Il clique sur "Commander" ou "Passer commande"
  3. Un chat s'ouvre immédiatement (sidebar ou modal) avec un message d'accueil automatique
  4. Le récapitulatif du panier est automatiquement partagé dans le chat au démarrage
  5. Le client échange avec l'admin pour convenir du mode de paiement et de livraison
  6. Une fois l'accord trouvé, l'admin crée la commande manuellement dans le dashboard
  7. Le client reçoit une confirmation par message dans le chat

Fonctionnalités du Chat

💬 Messagerie temps réel

  • WebSocket (Socket.io ou Supabase Realtime)
  • Indicateur "En train d'écrire..."
  • Accusés de réception (✓ envoyé, ✓✓ lu)
  • Partage de photos dans le chat

🤖 Message d'accueil automatique

  • Récapitulatif panier auto-injecté
  • Message de bienvenue personnalisé (prénom client)
  • Horaires de disponibilité affichés
  • Message hors-ligne si admin absent

📋 Modes de livraison

  • Livraison à domicile (adresse à préciser)
  • Retrait en boutique / locaux ILU SHOP
  • Frais de livraison convenus dans le chat
  • Délai estimé communiqué par l'admin

💳 Modes de paiement

  • Mobile Money (M-Pesa, Airtel Money, Orange Money)
  • Virement bancaire
  • Cash à la livraison ou au retrait
  • Tout autre mode convenu dans le chat

📁 Historique & Archivage

  • Chaque conversation liée à une commande est archivée
  • Accessible dans le dashboard admin (module Commandes)
  • Le client retrouve ses conversations dans son espace perso
  • Export PDF de la conversation possible

⚡ Réponses rapides (admin)

  • Templates de réponses prédéfinies
  • "Paiement reçu ✓", "Commande expédiée", etc.
  • Partage de numéro Mobile Money en 1 clic
  • Marquage "Commande confirmée" depuis le chat

Gestion Admin des Conversations

  • Dashboard chat centralisé dans /admin/commandes/chat
  • Liste de toutes les conversations actives triées par date/urgence
  • Badge de compteur sur conversations non lues
  • Possibilité d'assigner une conversation à un admin secondaire
  • Statuts conversation : En attente / En cours / Commande confirmée / Terminée
  • Filtres par statut, date, admin assigné
💡 Évolutivité

Ce système chat est conçu pour être remplacé à terme par une intégration de passerelle de paiement (Stripe, PayDunya, CinetPay...) quand l'accès sera disponible. L'architecture est modulaire : le module "chat commande" peut coexister avec un vrai tunnel de paiement, ou être remplacé complètement sans refactoring majeur.

Alertes NOUVEAU

Notifications
Temps Réel

Aucune commande ne doit être ratée — système d'alertes sonores pour l'admin, style WhatsApp, actif 24h/24.

Objectif Critique

🔔 Zéro commande ratée

L'admin peut avoir le tableau de bord ouvert dans un onglet en arrière-plan, être occupé sur autre chose, ou ne pas regarder l'écran. Le système de notifications doit l'alerter de façon impossible à rater : son distinctif, badge visible, notification système du navigateur. Comme WhatsApp — on entend le message même quand l'application est en arrière-plan.

Architecture Technique des Notifications

WebSocket temps réel

  • Socket.io ou Supabase Realtime
  • Connexion persistante admin ↔ serveur
  • Reconnexion automatique si déconnexion
  • Fonctionne en onglet arrière-plan

Web Notifications API

  • Notification système du navigateur (hors de l'onglet)
  • Demande de permission à la 1ère connexion admin
  • Compatible Chrome, Firefox, Edge, Safari
  • Cliquable → redirige vers la conversation

Sons (Web Audio API)

  • 2 fichiers audio distincts stockés localement
  • Son 1 doux : nouveau message (comme WhatsApp)
  • Son 2 fort : nouvelle commande (impossible à rater)
  • Paramètre volume + activation/désactivation dans les prefs admin

Dashboard Notifications Admin

  • Cloche 🔔 dans la navbar admin avec badge compteur de non-lus
  • Panel déroulant : liste des 10 dernières notifications avec horodatage
  • Clic sur une notification → redirige directement vers la conversation concernée
  • Bouton "Tout marquer comme lu"
  • Historique complet des notifications sur /admin/notifications
  • Filtres : type (message / commande / système), date, statut (lu/non-lu)
📱 Application Mobile Future

Quand une application mobile admin sera développée, les notifications seront étendues aux push notifications mobiles (Firebase Cloud Messaging). L'architecture WebSocket actuelle est compatible — les deux systèmes coexistent. L'admin recevra les alertes sur son téléphone même quand le dashboard n'est pas ouvert.
